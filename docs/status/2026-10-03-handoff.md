- Body delle PR con il template `.github/pull_request_template.md`. "Closes #N" oppure "Part of #N".

## Comandi di verifica locali

```bash
# Desktop (apps/desktop)
pnpm install --frozen-lockfile
pnpm --filter desktop exec svelte-kit sync      # genera $app/tsconfig, serve prima di typecheck
pnpm --filter desktop lint
pnpm --filter desktop typecheck
pnpm --filter desktop test                      # 483 test
pnpm --filter desktop build
pnpm --filter desktop test:e2e                  # Playwright, 10 test
bash scripts/design-lint.sh                     # niente font o colori hardcoded (desktop e macOS)

# Rust
cargo fmt --check && cargo clippy --workspace --all-targets -- --deny warnings && cargo test --workspace

# macOS: build e test (anche dei test UI)
xcodebuild build-for-testing -project apps/macos/cubelite/cubelite.xcodeproj -scheme cubelite -destination 'platform=macOS' -derivedDataPath /tmp/cubelite-build
```
